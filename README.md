# WebFileServer

WebFileServer是一个基于C++17开发的轻量级Web文件管理系统，采用cpp-httplib构建HTTP服务，使用SQLite作为本地数据库，
并通过nlohmann/json实现前后端JSON数据交互。项目支持用户注册、登录、退出登录、Token鉴权、密码哈希存储、文件上传、
文件大小限制、上传进度显示、文件列表查询、文件下载、文件删除、文件分享、分享列表管理以及取消分享等功能。
本项目主要用于学习C++后端开发、HTTP接口设计、SQLite数据库操作、文件系统管理、前后端交互以及中小型C++工程组织方式。

## 1.技术栈

编程语言：C++17
构建工具：CMake
HTTP服务：cpp-httplib
JSON解析：nlohmann/json
数据库：SQLite
前端页面：HTML+CSS+JavaScript
开发环境：Visual Studio/Windows
